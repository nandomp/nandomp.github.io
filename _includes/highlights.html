{% comment %} Renders _data/highlights.yml as a year-grouped timeline. The year is printed once per group, never on the individual items, and the markup is identical for every entry. The first `initial` items (default 10) are shown; the rest are rendered into the page too but carry --extra classes and are hidden with CSS until the "Show earlier highlights" button expands them. Nothing is fetched or generated at runtime, so this works on plain GitHub Pages, and with JS disabled (html.no-js) every item is visible and the button is hidden. A year group whose items are ALL beyond the cut is hidden as a whole, so no orphan year label is ever shown while collapsed. A group that straddles the cut keeps its single label and reveals its remaining items on expand. Usage: {% include highlights.html %} -> 10 shown, rest behind the button {% include highlights.html initial=5 %} -> 5 shown {% include highlights.html groups=1 %} -> only the most recent year {% endcomment %} {% assign highlight_groups = site.data.highlights | group_by: "year" %} {% if include.groups %}{% assign highlight_groups = highlight_groups | slice: 0, include.groups %}{% endif %} {% if include.skip_groups %}{% assign highlight_groups = highlight_groups | slice: include.skip_groups, 999 %}{% endif %} {% assign highlight_initial = include.initial | default: 10 %} {% assign highlight_count = 0 %}
