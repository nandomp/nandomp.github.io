{% comment %} Renders _data/highlights.yml as a year-grouped timeline. The year is printed once per group, never on the individual items, and the markup is identical for every entry — so the short homepage list and the full archive below it look exactly the same. Splitting is done by YEAR GROUP, never by item count, so the two blocks on the homepage can never show the same item twice and no year label is ever split across them. Adding a new item to the current year needs no changes. Usage: {% include highlights.html groups=1 %} -> the most recent year only {% include highlights.html skip_groups=1 %} -> every earlier year {% include highlights.html %} -> everything {% endcomment %} {% assign highlight_groups = site.data.highlights | group_by: "year" %} {% if include.groups %}{% assign highlight_groups = highlight_groups | slice: 0, include.groups %}{% endif %} {% if include.skip_groups %}{% assign highlight_groups = highlight_groups | slice: include.skip_groups, 999 %}{% endif %}
{%- for group in highlight_groups %}

{{ group.name }}

    {%- for item in group.items %}

    {%- if item.note %}
    {{ item.note | markdownify }}

    {% if item.venue %}{% if item.venue_url %}{{ item.venue }}{% else %}{{ item.venue }}{% endif %}{% endif %}{% for link in item.links %}{{ link.label }}{% endfor %}

    2. {%- endfor %}
